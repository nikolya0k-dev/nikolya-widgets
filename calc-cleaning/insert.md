# Калькулятор стоимости уборки квартиры — как вставить на сайт

Виджет — это один файл `widget.js`. Он подключается одной строкой и не зависит от стилей сайта:
вся разметка и оформление живут внутри Shadow DOM, поэтому тема сайта не ломает виджет,
а виджет не меняет ничего на странице.

## Код для вставки

```html
<div id="calc-cleaning"></div><script src="https://ВАШ-САЙТ.netlify.app/calc-cleaning/widget.js"></script>
```

Замените `https://ВАШ-САЙТ.netlify.app` на адрес, где лежит `widget.js`
(Netlify, свой хостинг, папка в WordPress — подойдёт любой адрес с https).

## Tilda

1. В редакторе страницы нажмите «Все блоки» → «Другое» → **T123 «HTML-код»**
   (или найдите поиском по блокам «T123»).
2. Нажмите «Контент» и вставьте код для вставки целиком.
3. Сохраните и нажмите «Опубликовать».

> В режиме редактирования Tilda не выполняет скрипты — там будет пустое место.
> Виджет появится в «Предпросмотре» и на опубликованной странице.
> Чтобы виджет не прилипал к краям на мобильных, в настройках блока можно задать
> отступы сверху/снизу; ширина подстраивается автоматически.

## WordPress

1. Откройте страницу в редакторе (Gutenberg), нажмите «+» → блок **«Произвольный HTML»**
   (Custom HTML).
2. Вставьте код для вставки и обновите страницу.
3. В классическом редакторе вставляйте код на вкладке «Текст», а не «Визуально».

> Скрипты в HTML-блоке может сохранять только пользователь с правами администратора/редактора
> (право `unfiltered_html`). Если после сохранения код пропал — вставьте его под администратором.
> Плагины оптимизации (Autoptimize, WP Rocket и т. п.) могут откладывать скрипты — виджет это
> выдерживает, исключать его не обязательно.

## Обычный HTML-сайт

Вставьте код в то место `<body>`, где должен быть виджет:

```html
<section class="my-section">
  <div id="calc-cleaning"></div><script src="https://ВАШ-САЙТ.netlify.app/calc-cleaning/widget.js"></script>
</section>
```

Скрипт можно подключить и в конце страницы или с `defer` — виджет найдёт контейнер по `id`.
Ширина виджета — 100% контейнера, но не больше `maxWidth` из настроек; по центру.

## Настройки

Всё, что меняется под клиента, — в объекте `CONFIG` в самом начале `widget.js`:

| Что | Где в CONFIG |
| --- | --- |
| Номер WhatsApp и ник Telegram | `contacts.whatsapp` (только цифры, с кодом страны), `contacts.telegram` (без @) |
| Цвета | `colors` — акцент, фон, текст, рамки, цвета кнопок мессенджеров |
| Скругление и ширина | `radius`, `maxWidth` |
| Тексты интерфейса и шаблон сообщения | `texts` |
| Контент и цены | типы уборки, цены за м² и санузел, диапазон площади, доп. услуги, минимальный заказ |
| id контейнера | `mountId` (если меняете — поменяйте и в `<div id="...">`) |

### Как считается цена

`итог = площадь × цена за м² типа + санузлы × цена санузла типа + выбранные доп. услуги`

Если итог меньше `minOrder`, добавляется строка «Доплата до минимального заказа». Итог округляется вверх до `roundTo`.

## Отправка в мессенджеры

- **WhatsApp** открывает чат с номером через `https://wa.me/<номер>?text=...` — текст подставляется в поле ввода.
- **Telegram** открывает чат с ником через `https://t.me/<ник>?text=...` — текст подставляется в поле ввода
  (параметр `text` поддерживается официально; старые версии приложений могут его игнорировать).
- При нажатии на любую кнопку текст дополнительно копируется в буфер обмена и виджет показывает подсказку —
  если мессенджер текст не подставил, его можно просто вставить.

## Проверка

- `demo.html` — чистая страница с примером вставки.
- `test-noisy.html` — страница с агрессивными глобальными стилями (сброс отступов, Comic Sans,
  uppercase, свои стили `button`, `input`, `h1–h3`, `svg`). Виджет на ней выглядит так же, как на demo.html.
